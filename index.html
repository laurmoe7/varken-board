Sync and backup

Everything is already saved in this browser. Sync also keeps a copy in a private GitHub repo, so nothing is lost and Claude can read your board.

Make a private repo for the data. Then make a fine-grained token (GitHub, Settings, Developer settings, Personal access tokens) for only that repo with Contents: Read and write. It stays in this browser.

Export has the board's text only; images travel through sync.

Unused pictures. Pictures you removed, replaced or drew over stay stored. This looks for ones no item uses; it deletes nothing until you say so.

New project

A gallery is a separate area for ideas where the pictures come first, shown under the project in the sidebar. Slot tags let you label and filter its cards.
Draw on the picture. "Save" replaces it on this item, "Save as copy" keeps the original too.
