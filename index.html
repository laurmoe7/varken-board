Everything is already saved in this browser. Sync also keeps a copy in a private GitHub repo, so nothing is lost and Claude can read your board.

Make a private repo for the data. Then make a fine-grained token (GitHub, Settings, Developer settings, Personal access tokens) for only that repo with Contents: Read and write. It stays in this browser.
